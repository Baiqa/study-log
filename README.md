# Учебный журнал

Личный статический трекер обучения на HTML, CSS, ванильном JavaScript и Supabase. Данные хранятся в `study_items` под RLS и привязаны к текущему пользователю.

Сайт: https://baiqa.github.io/study-log/

## Локальный запуск

Открой `index.html` через любой статический сервер, например:

```powershell
python -m http.server 8000
```

Затем перейди на http://localhost:8000.
